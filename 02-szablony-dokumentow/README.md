# Warstwa 2 — szablony dokumentów

Szablony `.md` dla poszczególnych typów dokumentów IRIN (np. viewbook, karta usługi BUR, certyfikat, papier firmowy). Każdy szablon to karta specyfikacji treści i wymogów regulacyjnych — rozróżnia jawnie, co jest prawnie obowiązkowe (patrz `/01-baza-wiedzy/prawo/`), co jest konwencją organizacyjną IRIN, a co jest swobodnym wyborem projektowym. Żaden plik tutaj nie opisuje układu graficznego, kolorów ani typografii — to zadanie warstwy 3 (`/03-pakiet-claude-design/`); w miejscu dawnych wytycznych wizualnych każdy szablon odsyła do aktualnego brandbooku IRN.

## Pliki

- [`program-szkolenia.md`](program-szkolenia.md) — specyfikacja programu szkolenia: metryczka, kanały finansowania, cel edukacyjny, efekty uczenia się, ramowy program, kadra, karty usług.
- [`prezentacja-sprzedazowa.md`](prezentacja-sprzedazowa.md) — struktura prezentacji produktowo-sprzedażowej dla klienta (dziesięć slajdów) wraz z zasadami twardymi komunikacji o dofinansowaniu.
- `karta-uslugi-bur.md`, `viewbook.md`, `certyfikat.md`, `papier-firmowy.md`, `material-sprzedazowy.md` — jeszcze nie utworzone, patrz `/PLAN.md`.
