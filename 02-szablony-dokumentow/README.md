# Warstwa 2 — szablony dokumentów

Szablony `.md` dla poszczególnych typów dokumentów IRIN (np. viewbook, karta usługi BUR, certyfikat, papier firmowy). Każdy szablon to karta specyfikacji treści i wymogów regulacyjnych — rozróżnia jawnie, co jest prawnie obowiązkowe (patrz `/01-baza-wiedzy/prawo/`), co jest konwencją organizacyjną IRIN, a co jest swobodnym wyborem projektowym. Żaden plik tutaj nie opisuje układu graficznego, kolorów ani typografii — to zadanie warstwy 3 (`/03-pakiet-claude-design/`).
