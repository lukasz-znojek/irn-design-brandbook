# orkiestracja/

Minimalna warstwa orkiestracji — dwa pliki, nic więcej. Nie ma tu kontraktów dla subagentów ani specyfikacji workflow YAML: przy obecnym rozmiarze zespołu (Claude Code + founder) taka rozbudowa tylko wydłużałaby start zadania. Dwa pliki wystarczają, bo pokrywają jedyne dwie realne potrzeby: "co w ogóle jest w tym repo i w jakiej kolejności to czytać" (`README.md`, ten plik) oraz "jak zacząć konkretne zadanie" (`karta-startowa.md`).
