# Warstwa 3 — pakiet i prompt dla Claude Design

Tu trafia paczka wejściowa i prompt bazowy przekazywane do Claude Design, gdzie faktycznie powstaje kompozycja, układ strony i grafika. Ta warstwa odwołuje się do treści z warstwy 1 i szablonów z warstwy 2, ale sama nie zawiera gotowych treści merytorycznych ani finalnej grafiki — jedynie instrukcje i materiały wejściowe dla Claude Design.

Katalog `zlecenia/` przechowuje wypełnione sekcje „Zlecenie” dla konkretnych dokumentów wraz ze składem paczki i protokołem pomiaru; pierwsze: `zlecenia/pilot-papier-firmowy.md`.
