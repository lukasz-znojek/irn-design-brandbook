# prawo/

Obowiązujące przepisy i regulacje, którym podlegają dokumenty IRIN: Krajowy Fundusz Szkoleniowy (KFS), Baza Usług Rozwojowych / certyfikaty BUR, regulacje pożyczek UE/BGK. Każdy plik tu jest źródłem do rozstrzygania, które elementy dokumentu w warstwie 2 są prawnie obowiązkowe. Nie zawiera treści samych dokumentów ani wytycznych organizacyjnych IRIN (patrz `../uslugi/`).
