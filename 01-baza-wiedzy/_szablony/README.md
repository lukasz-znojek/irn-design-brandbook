# _szablony/

Szablony do pisania kart w warstwie 1 (`01-baza-wiedzy/`) — nie mylić z `02-szablony-dokumentow/`, która specyfikuje dokumenty wydawane na zewnątrz (viewbook, karta usługi BUR, certyfikat). Karty tworzone tym szablonem opisują fakty i zasady jednego produktu/kanału (np. KFS, PSF, pożyczki UE/BGK) i trafiają do `prawo/` albo `uslugi/`, zależnie od tego, czy opisują przepis, czy konwencję organizacyjną IRIN.

- `karta-produktu.md` — szablon karty pojedynczego produktu/kanału finansowania albo wsparcia.
