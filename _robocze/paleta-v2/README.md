# _robocze/paleta-v2/

**Archiwum. Nie jest źródłem prawdy.** Obowiązująca paleta to `../../01-baza-wiedzy/identyfikacja/paleta-barw.md` - jeśli szukasz kolorów IRIN, idź tam.

Tu leży materiał porównawczy, na podstawie którego founder wybrał wariant 2 „Kaszmir Wyciszony” (2026-09-02):

- `palette-options-v2.md` - siedem wariantów palety, po 15 tokenów, ze zmierzonymi kontrastami WCAG i trade-offami.
- `palette-preview-v2.md` - mapa element - token - HEX dla wspólnego układu demonstracyjnego.
- `palette-preview-v2.dc.html` - renderowany podgląd siedmiu wariantów na identycznym układzie.
- `palette-options-v2.json` - dane maszynowe wszystkich siedmiu wariantów.

Sześć odrzuconych wariantów zostało zachowanych celowo: to zapis tego, co zmierzono i odrzucono, przydatny na wypadek powrotu do decyzji. **Żadnego z nich nie wolno użyć jako palety** bez nowej decyzji foundera.

Odrzucona przy okazji propozycja dodatkowa: wariant 6 „Druk Ekonomiczny” jako osobny tryb monochromatyczny dla zaświadczeń KFS. Founder wybrał jedną paletę na wszystko.
