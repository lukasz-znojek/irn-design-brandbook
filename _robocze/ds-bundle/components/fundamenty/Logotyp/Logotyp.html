Przestrzeń ochronna: x = wysokość liter sygnetu. Miara względna, skalująca się ze znakiem, nie stała liczba milimetrów. Żaden element graficzny, tekstowy ani krawędź strony nie wchodzi bliżej niż x z każdej strony. Znak w minimalnym rozmiarze nadal wymaga świadomego odsunięcia — jeden margines strony nie załatwia tego dla wszystkich wielkości.
Cztery zakazy, wszystkie wiążące. 1. Nie zmieniamy koloru — na ciemnym tle wersja odwrócona, nie przebarwiona. 2. Nie obracamy, nie pochylamy, nie odbijamy lustrzanie. 3. Nie dodajemy cienia, poświaty ani obrysu. 4. Nie rozciągamy nieproporcjonalnie.
Dlaczego zakaz koloru jest najważniejszy: pliki źródłowe nie niosą własnej palety, więc bez tej reguły każde zlecenie mogłoby pokolorować znak według uznania. Logotyp jest jedynym elementem tożsamości, którego nie da się odtworzyć z innej specyfikacji po zepsuciu — paletę, siatkę i skalę można przeliczyć, znaku nie.
