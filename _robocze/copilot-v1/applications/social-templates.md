# Social templates

## Purpose
- Define a repeatable social publishing system for IRIN across LinkedIn, X, and Instagram.
- Translate the brand's editorial, engineered, warm-minimal character into channel-ready layouts and copy rules.
- Keep social output consistent with `../identity/typography-system.md`, `../identity/color-system.md`, and `../docs/03_quality-bar.md`.
- Give designers, marketers, and founders enough specificity to publish without improvising the brand each time.
- Protect the fixed IRIN wordmark by clarifying where it appears, at what scale, and when it should stay absent.
- Ensure every post feels boutique and precise rather than loud, trend-chasing, or startup-generic.

## When to use
- Use when creating recurring organic social posts for IRIN-owned channels.
- Use when adapting long-form thinking into short social assets.
- Use when building launch announcements for a product, article, or studio update.
- Use when briefing contractors or collaborators who need exact platform sizes and safe zones.
- Use when turning case-study facts into quote cards, stat cards, or carousels.
- Use when preparing founder-led commentary that must stay aligned with the studio voice.
- Use when scheduling a content batch for one month or one campaign flight.
- Use when a platform introduces a new crop behavior and template sizes need validation.
- Use for social content only, not for paid display, email, or website banners.
- Use alongside `../applications/website-guidelines.md` when repurposing web launches into social teasers.
- Use alongside `../templates/campaign-brief-template.md` when social is part of a larger launch plan.

## Inputs
- Approved message hierarchy: one primary idea, one proof point, one action.
- Final copy draft aligned to IRIN tone guidance from the verbal system.
- Approved brand assets: fixed wordmark, avatar crop, and any supporting imagery.
- Source facts that can be verified: dates, metrics, quotes, client names, URLs.
- Reference links to `../identity/color-system.md` and `../identity/typography-system.md`.
- Platform destination and post type: single image, carousel, header, or profile asset.
- Accessibility notes including alt text draft and contrast check results.
- Export intent: organic post, pinned post, campaign burst, or evergreen library asset.
- Owner and reviewer names so the approval path is explicit.
- Publishing context such as launch date, event timing, or embargo.

## Outputs
- Platform-specific artboards at the exact export dimensions listed below.
- A caption draft with opening line, supporting sentence, and CTA or close.
- A safe-zone checked asset that survives in-feed crops and profile overlaps.
- A filename that identifies platform, date, topic, and version.
- Alt text or accessibility notes for the post and any text-heavy graphics.
- A source record for metrics, claims, and quotes used in the asset.
- One selected template type: quote card, stat card, announcement, or carousel cover.
- A handle and hashtag decision that follows the rules in this document.
- A review-ready export set for design QA using `../templates/design-qa-checklist.md`.

## Owner
- Primary owner: Brand design lead.
- Content owner: Marketing or studio communications lead.
- Final approver: Founder or delegated brand steward for high-visibility posts.
- Accessibility check owner: Designer preparing exports.
- Data accuracy owner: Person closest to the source metric or announcement.
- Archive owner: Operations or marketing maintaining the shared social library.

## Quality criteria
### Channel specs
| Platform | Asset | Size | Notes |
| --- | --- | --- | --- |
| LinkedIn | Feed post | 1200 x 1200 px | Default square for most editorial posts |
| LinkedIn | Landscape link image | 1200 x 627 px | Use only when URL preview is suppressed intentionally |
| LinkedIn | Cover image | 1584 x 396 px | Keep key content centered due to responsive crop |
| LinkedIn | Profile image | 400 x 400 px | Usually avatar crop, not full wordmark |
| X | Post image | 1600 x 900 px | Design to 16:9 and verify mobile crop |
| X | Header image | 1500 x 500 px | Keep content out of left profile overlap |
| X | Profile image | 400 x 400 px | Use approved avatar crop |
| Instagram | Feed post | 1080 x 1350 px | Default portrait for reach and readability |
| Instagram | Square post | 1080 x 1080 px | Use when adapting existing square work |
| Instagram | Story | 1080 x 1920 px | Keep live UI overlays clear |
| Instagram | Profile image | 320 x 320 px | Export from approved avatar source |

### Safe zones
- LinkedIn feed: keep all essential text within a centered 1040 x 1040 px area on square posts.
- LinkedIn cover: keep critical type and marks inside the middle 1350 x 220 px band.
- X post image: keep primary message inside a centered 1360 x 700 px safe field.
- X header: avoid the left 320 px and bottom 140 px where profile photo and responsive crops interfere.
- Instagram feed portrait: keep key text inside 980 x 1180 px to survive feed trims.
- Instagram story: keep live UI clear by leaving at least 250 px top and 320 px bottom free of critical copy.
- Profile images: never place fine text, only approved icon crop or simplified mark usage if already defined.
- Wordmark use: avoid placing the full fixed wordmark in avatars where legibility collapses.

### Template types
- Quote card: one sentence or two short lines, generous margins, speaker credit small but legible.
- Stat card: one headline metric, one qualifier line, one source line.
- Announcement: one action-focused headline, one supporting line, optional date or availability tag.
- Carousel cover: one thesis line that earns the swipe, never a paragraph.
- Carousel body: consistent slide numbering, restrained accent color, one idea per slide.
- Process snippet: use only when showing system thinking, wireframes, or editorial observations.
- Event note: reserved for talks, panels, or launches with a time-sensitive CTA.

### Caption voice rules
- Open with a clear observation, claim, or invitation; avoid hype openings.
- Prefer short paragraphs of one to three sentences.
- Use specific nouns: platform, system, workflow, tool, interface, team.
- Write with quiet confidence; avoid chest-beating language.
- Avoid startup-generic verbs such as empowering, revolutionizing, disrupting, and transforming everything.
- If sharing a stat, qualify the context in the caption even if the card shows the number.
- Close with a light CTA: read, see, explore, ask, or follow the thread.
- Use em dashes sparingly; IRIN voice is editorial, not theatrical.
- Avoid emoji unless the post context genuinely requires one, and never use more than one.
- Avoid stacked hashtags inside the main body of the caption.

### Hashtag and handle rules
- LinkedIn: zero to three hashtags maximum, placed at the end, sentence case in body copy.
- X: zero to two hashtags maximum, only when they aid discovery beyond the follower graph.
- Instagram: three to five hashtags maximum, selected for relevance not volume.
- Prefer branded or domain-specific tags over broad trend tags.
- Tag partner handles only when there is a real relationship, collaboration, or quoted source.
- Do not tag aspirational brands to borrow attention.
- Keep handles out of the artwork unless the asset is a collaboration announcement.
- If the caption contains more than one handle, verify legal and relationship approval.

### Layout and brand rules
- Use Manrope only, following the approved hierarchy in `../identity/typography-system.md`.
- Keep background fields simple: solid, soft gradient, or one restrained texture.
- Use the fixed IRIN wordmark only from approved assets and never redraw or restyle it.
- Leave visible negative space; the brand should feel engineered, not crowded.
- On dark backgrounds, use high-contrast type and avoid low-opacity gray body copy.
- On light backgrounds, avoid faint strokes or hairline dividers that disappear in compression.
- Use one accent color per asset family, not a rainbow treatment.
- If imagery is included, crop with intent and avoid stock-photo energy.

### Production checks
- Verify pixel dimensions before export, not after upload.
- Check text size on mobile previews at 100 percent.
- Confirm no line of copy exceeds the safe-zone width awkwardly.
- Run contrast checks to meet WCAG AA where text is embedded in graphics.
- Export PNG unless a photo-heavy JPG yields materially better file weight.
- Keep file sizes reasonable for upload speed without visible banding.
- Store source and final exports in clearly named folders by platform and campaign.

## Example (IRIN)
- Scenario: IRIN is announcing a new studio essay about precision in product delivery.
- Platform: LinkedIn square feed post at 1200 x 1200 px.
- Template type: Quote card.
- Headline on card: "Precision is not polish added late. It is structure made visible." 
- Supporting micro-line: "From the latest IRIN field note on product design and engineering." 
- Layout: dark graphite background, warm off-white type, subtle rule near footer.
- Wordmark: small approved lockup in the lower-left corner with ample margin.
- Caption opening: "Most delivery problems do not start in execution. They start in ambiguity." 
- Caption middle: "We wrote a short field note on how precision shows up in interfaces, roadmaps, and the small decisions teams repeat every week." 
- Caption close: "Read the essay: irin.studio/journal/precision-made-visible" 
- Hashtags: `#ProductDesign #DesignSystems #EngineeringLeadership`.
- Why it fits: it sounds specific, grounded, and editorial rather than promotional.
- Adaptation for X: reduce caption to a two-sentence thread opener and keep the card at 1600 x 900 px.
- Adaptation for Instagram: convert to a 1080 x 1350 px portrait with larger text and shorter footer line.

## Common failure modes
- Designing one master asset and forcing it unchanged across all platforms.
- Using too much copy on the artwork because the caption was not doing enough work.
- Letting small text drift into crop-risk areas on covers and stories.
- Treating hashtags as filler instead of editorial metadata.
- Overusing gradients, blur, or trendy visual noise that dates quickly.
- Adding unapproved logo variations or retyping the wordmark.
- Writing captions that sound like generic agency marketing.
- Publishing a stat without its timeframe or source.
- Exporting an image that technically fits but feels soft on retina screens.
- Forgetting alt text for text-forward assets.

## How to avoid generic output
- Start from a concrete observation, not a category statement.
- Reference the actual audience: growth-stage product teams, founders, or operators.
- Use proof points from work, essays, launches, or client outcomes.
- Prefer language about systems, clarity, and craft over buzzwords.
- Keep the composition restrained so confidence comes from precision, not decoration.
- Write as if IRIN is already trusted and does not need to perform certainty loudly.
- Show the thinking behind the post in one line if needed; that creates depth.
- Cross-check every asset against `../docs/03_quality-bar.md` before approval.
- If a sentence could belong to any consultancy, rewrite it until it could only belong to IRIN.
